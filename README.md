# 📌 Project Overview

The **Google Expense Sharing Analysis Project** is a Python-based data analysis project designed to analyze and visualize shared expenses among multiple individuals.

This project demonstrates how expense data can be processed, analyzed, and transformed into meaningful financial insights using Data Analytics techniques.

The project performs:

- Expense tracking
- Expense categorization
- Contribution analysis
- Trend analysis
- Data visualization
- Budget insights generation

---

# ❗ Problem Statement

Managing shared expenses manually can become confusing when multiple people contribute to different categories such as food, travel, bills, and shopping.

Common challenges include:

- Tracking who spent the most
- Identifying high-expense categories
- Understanding spending patterns
- Monitoring monthly expenses
- Making better budgeting decisions

This project solves these challenges using Python-based data analysis and visualization.

---

# 🎯 Business Objective

The goal of this project is to:

- Analyze shared expenses efficiently
- Identify major spending categories
- Track contribution by individuals
- Generate insights for budgeting
- Visualize financial data for better decision-making
